# Day-12: Personal Savings Goal Tracker

## About
A simple Python project that helps users track their savings progress toward a financial goal.

## Features
- Enter a savings goal and current savings.
- Calculate the remaining amount.
- Calculate savings progress as a percentage.
- Display a message when the goal is reached.
- Validate zero or negative amounts.
- Prevent remaining balance and progress from exceeding their limits.

## Technologies Used
- Python 3

## How to Run
Open the terminal in the main project folder and run:

```bash
python3 Day-12/savings_goal_tracker.py
```

## Example
Savings goal: ₹10,000
Already saved: ₹2,500
Amount remaining: ₹7,500
Savings progress: 25%

## Learning Outcomes
Practiced user input, numeric calculations, conditional statements, validation, and formatted output.
